Această lucrare tratează proiectarea unui sistem e-medicine pentru analiza datelor
epidemiologice prin modele compartimentale, cu modelul SIDARTH folosit ca direcție
principală de explorare. Spre deosebire de SIR, care reduce dinamica la trei
stări agregate, SIDARTH separă infecțiile nedepistate, cazurile diagnosticate,
formele simptomatice, formele severe și vindecările. Această granularitate face
modelul mai potrivit pentru discutarea efectelor testării, diagnosticării și
severității clinice asupra evoluției unei epidemii.

SIR rămâne prezent în lucrare ca model secundar, folosit pentru comparații și
pentru verificarea comportamentului numeric al implementărilor. Sistemul construit
separă explicit stocarea datelor, expunerea API-ului și execuția simulărilor.
Datele epidemiologice sunt persistate într-o schemă relațională compatibilă
PostgreSQL, rulată peste YugabyteDB, iar simulările sunt executate asincron de
runner-e specializate, coordonate prin Redis.

Componenta web, alcătuită dintr-un API Go și o interfață Vue.js, oferă fluxurile
necesare încărcării seturilor de date, lansării simulărilor, urmăririi statusului și
vizualizării traiectoriilor compartimentale. Accentul lucrării cade pe legătura
dintre modelul matematic, implementarea numerică și arhitectura software care face
posibilă evaluarea reproductibilă a rezultatelor pentru modele cu grade diferite
de complexitate.

\bigskip
\noindent\textbf{Cuvinte cheie:} model SIDARTH, model SIR, epidemiologie computațională, e-medicine,
calcul comparativ, YugabyteDB, Kubernetes, Go, Vue.js, benchmark de performanță.
