Lucrarea de față prezintă proiectarea și realizarea unui sistem e-medicine dedicat
analizării și monitorizării datelor epidemiologice, având ca fundament matematic
modelul SIR (Susceptibili--Infectați--Recuperați). Modelul este implementat și testat
comparativ în trei limbaje de programare cu utilizare intensă în calculul științific:
R, Julia și Python.

Implementările sunt evaluate pe mai multe configurații hardware, urmărindu-se
comportamentul algoritmilor din perspectiva performanței și a scalabilității în funcție
de dimensiunea seturilor de date procesate. Datele epidemiologice utilizate sunt stocate
într-o bază de date distribuită YugabyteDB, rulată într-un cluster Kubernetes, asigurând
disponibilitate ridicată, toleranță la erori și distribuție eficientă a datelor.

Pentru centralizarea, compararea și vizualizarea rezultatelor este dezvoltată o aplicație
web dedicată, compusă dintr-un API backend implementat în limbajul Go și o interfață
frontend realizată în Vue.js. Aceasta oferă o perspectivă unificată asupra performanței
și comportamentului modelelor epidemiologice analizate, permițând consultarea
rezultatelor rulărilor, a seturilor de date utilizate și a graficelor asociate.

\bigskip
\noindent\textbf{Cuvinte cheie:} model SIR, epidemiologie computațională, e-medicine,
calcul comparativ, YugabyteDB, Kubernetes, Go, Vue.js, benchmark de performanță.
