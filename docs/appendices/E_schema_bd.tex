\chapter{Schema Bazei de Date}
\label{app:schema_bd}

Anexa include migrațiile SQL care definesc schema relațională folosită de API și
runner-e. Primele migrații creează structura inițială; cele intermediare adaugă
studiile, membership-ul, flag-ul de super-admin, legătura \texttt{study\_id}
pentru resursele epidemiologice și extinderile pentru modelele
\texttt{lstm} și \texttt{script}; ultimele introduc tabelele auxiliare
(runner-e plug-in, draft-uri de script) și îmbogățirea schemei de date
epidemiologice cu metrici suplimentare (decese, spitalizări, ATI, vaccinări,
teste, indici de răspuns sanitar).
